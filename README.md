# Запуск проекта через Docker

## Установка
1. Убедитесь, что у Вас установлены Docker и Docker Compose.
2. Склонируйте репозиторий и перейдите в его директорию.
3. Создайте файл `.env` в корне проекта на основе шаблона, предоставленного в `.env.example`.

## Запуск проекта
Для запуска всех сервисов используйте команду:
```bash
docker-compose up --build
После выполнения этой команды будут собраны образы, запустятся сервисы, будут применены миграции, запустится сервер.

Проверка работоспособности
Для проверки основных сервисов нужно выполнить команды:
Проверка статуса всех контейнеров
docker-compose ps
